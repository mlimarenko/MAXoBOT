# Разработка и релизы

## Рабочий цикл

1. Создайте ветку под задачу.
2. Внесите изменения небольшими логическими шагами.
3. Добавьте/обновите тесты и документацию.
4. Прогоните обязательные проверки перед PR.

## Обязательные проверки

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo test --workspace --all-features
cargo build --workspace --all-features --examples
```

## Релизный минимум

- Обновлен `CHANGELOG.md`.
- Проверены тесты/линтеры.
- Нет секретов в коде, фикстурах и логах.
- Обновлены примеры и README при изменении публичного поведения.

## Нежелательные практики

- Коммит реальных токенов/секретов.
- Ломающие изменения без миграционных заметок.
- Большие PR без разделения на логические этапы.
