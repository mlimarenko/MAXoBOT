# Как вносить вклад в MAXoBOT

Спасибо за вклад. MAXoBOT — публичный Rust SDK, поэтому для каждого изменения важны контракт, тесты и понятный review.

## Базовые правила

- Один pull request = одна логическая задача.
- По возможности делайте обратно-совместимые изменения.
- Не добавляйте токены, секреты и приватные данные в код, тесты и документацию.
- Изменения публичного поведения обязательно сопровождайте тестами и обновлением документации.

## Локальная проверка перед PR

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo test --workspace --all-features
cargo build --workspace --all-features --examples
```

## Требования к PR

- Кратко опишите проблему и решение.
- Добавьте/обновите тесты для новой логики.
- Обновите `README.md` и `CHANGELOG.md`, если есть пользовательские изменения.
- Для ломающих изменений добавьте явные шаги миграции.
